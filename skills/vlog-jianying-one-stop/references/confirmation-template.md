# 一次确认模板

## 计划拍摄模式

只展示一次完整方案，不让用户逐项填表。

```markdown
## 拍摄方案

一句话成片：<最终视频讲什么、让观众感到什么>
平台 / 画幅 / 时长：<平台> / <画幅> / <时长>

### 故事顺序
- 00 钩子：<作用和画面方向>
- 01 <beat 名>：<作用、预计秒数>
- ...

### 傻瓜式拍摄脚本
| 编号 | 故事段 | 重要性 | 景别 | 画面在做什么 | 角度（可选） |
|---|---|---|---|---|---|
| S01 | beat_01 | 必拍 | 中景 | <一句人话说明> | <可留空> |

### 实际拍摄顺序
按地点或场景列出 S 编号，减少来回切换。

地点发生变化时，方案会自动加入一条“出发 / 在路上 / 到达”过场必拍项；随手拍即可，不要求构图或摄影参数。

确认后：按这张表拍摄原素材 → 提供素材 → 自动匹配 → 缺关键故事段才补拍 → 自动剪辑成片。

如无修改，请回复：确认拍摄方案。
```

用户明确说“直接出脚本”“不要确认”时，输出最终脚本后结束本阶段，不要求确认。

## 已有素材模式

用户没有明确故事线时，最多给出 2–3 个素材确实能支撑的故事方案。每个方案只写：

- 一句话故事。
- 4–6 个 beat。
- 优点。
- 素材上的明显短板。

结尾只要求用户选择一个方案。选定后不再提交完整剪辑确认单。
