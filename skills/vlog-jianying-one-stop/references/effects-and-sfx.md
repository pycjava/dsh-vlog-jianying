# 轻网感画面特效、人物特效与音效

## 总原则

- 默认值始终是 `none`。特效是允许使用的强化手段，不是每个 beat 的完成指标；情绪不匹配时必须不用。唯一例外是所有成片结尾强制使用 `tv_shutdown`，随后显示固定“晚安”结束卡。
- 先让故事、镜头、人物原声和字幕成立，再判断是否需要强化。不得用特效掩盖素材普通、故事不清或人声听不清。
- 每个 beat 最多设置一个画面或人物特效重点，也可以完全没有。同一瞬间画面特效与人物特效二选一；确有帮助时可再配一个轻音效，但不得默认三者叠加。
- 完整观点、正常对白、真诚安静情绪默认不用干扰性特效。字幕位置固定；特效置于字幕层下方，不移动字幕，也不为特效重新改变字幕或画面构图。
- 片段切换踩点只约束视频边界。特效不强制踩 BGM；音效只对齐真实动作、结果或场景切换。
- 真实原声优先。原声已经表达清楚时不补同类音效；人物说话和关键互动不得被音效覆盖。
- 只使用剪映内可合法使用的效果/音效或用户提供的本地合法素材。跟踪、抠像、描边不稳定时直接取消，不得因此拒绝素材。

## 判断顺序

```text
画面和原声已经成立？ → 是：默认 none
是否有明确换场、移动、高光、结果或人物反应？ → 否：none
强化对象是整体画面还是人物？ → 二选一
真实声音是否已经足够？ → 是：音效 none
加入后是否更自然、更好懂？ → 否：全部撤销
```

## 画面特效白名单

画面特效作用于整体画面，不专门抠出人物。

| 值 | 效果 | 允许使用 | 不使用 |
|---|---|---|---|
| `none` | 无 | 默认 | — |
| `push_in` | 轻微推近 | 重点结论之后、结果出现、整体画面需要轻聚焦 | 普通长对白、反复缩放、明显损失画质 |
| `blur_reveal` | 短暂模糊后清晰 | 时间、地点或状态明显变化 | 硬切已自然、安静情绪、持续模糊 |
| `flash` | 短闪白/轻曝光闪 | 出发、登机、落地等短促兴奋节点 | 对白中间、安静情绪、连续闪烁 |
| `motion_blur` | 轻运动模糊/短拖影 | 行走、乘车、机场移动、旅行蒙太奇 | 静止聊天、素材本身已明显晃动 |
| `frame_freeze` | 整帧短定格 | 明确结果、表情或反差需要停一下 | 没有清楚落点、截断说话、真诚观点 |
| `tv_shutdown` | 电视关机/TV Off | 所有视频最后一个真实画面结束时强制使用 | 不得用于正文，不得因情绪判断取消 |

场景特效不能替代“过场或硬切”判断。先确定真实过场或硬切，再决定是否附加 `blur_reveal` 或 `flash`；没有合适情绪就保持硬切。

### 固定结尾例外

1. 结束最后一个真实故事画面后，执行一次电视关机效果，使画面收缩为亮线/亮点并进入纯黑。
2. 优先使用剪映内含义相同的“电视关机”“TV Off”或“老电视关屏”效果；当前版本没有时，用缩放/蒙版关键帧模拟“画面压成横向亮线 → 收成亮点 → 黑屏”，不得直接省略。
3. 关机完成后在黑屏中央显示约 1 秒“晚安”结束卡；它属于字幕系统的 `end_card`，不添加人物特效。
4. `tv_shutdown` 是全局结束模板，不占正文 beat 的特效名额。结尾模板计入目标成片时长，不能让视频因固定片尾超出用户目标。
5. 不强制添加关机音效；如剪映效果自带声音且显得突兀或盖住结尾原声/BGM，关闭该声音。BGM 在最终画面和结束卡期间自然淡出。

## 人物特效白名单

人物特效只强化承担当前动作、反应或笑点的人。

| 值 | 效果 | 允许使用 | 不使用 |
|---|---|---|---|
| `none` | 无 | 普通对白、观点、真诚情绪或无明确反应 | — |
| `subject_zoom` | 人物局部轻微放大 | 迟疑、惊讶、无奈、偷笑等明确反应 | 普通说话、反复缩放、放大后模糊 |
| `subject_freeze` | 以人物反应为重点的短定格 | 明确笑点或结果后的反应 | 与 `frame_freeze` 同时使用、切断说话 |
| `outline` | 短时浅色细描边 | 多人或复杂背景中需要指出当前人物 | 人物已经突出、长时间跟随、抠像不稳 |
| `reaction_symbol` | 单个问号、感叹号或极短提示 | 笑点本身成立，只补一点语气 | 制造不存在的笑点、遮脸、与主字幕争抢 |
| `subject_track` | 人物跟踪强调 | 多人场景或移动中需要持续找到关键人物 | 跟踪跳动、自动改构图、普通单人镜头 |

禁止自动使用瘦脸、大眼、身体变形、夸张大头、分身、长时间发光、满屏表情包或多种人物特效叠加。

## 音效白名单

音效是后期添加的短声音，不包括人物原声、环境原声、旁白和 BGM。

| 值 | 效果 | 允许使用 | 不使用 |
|---|---|---|---|
| `none` | 无 | 默认；原声已经成立 | — |
| `transition` | 轻转场音 | 明显时间/地点变化且自然声不足 | 每个切点都加、有真实过场声时重复添加 |
| `cue` | 轻提示音 | 物品、手机内容或场景信息被揭示 | 每条字幕出现都加 |
| `result` | 轻结果音 | 递物完成、目标完成或铺垫得到回应 | 普通动作、现场已有清楚落点声 |
| `comedy` | 克制趣味音 | 明确迟疑、尴尬停顿或已成立的笑点 | 罐头笑声、用音效制造笑点、覆盖真实笑声 |
| `action` | 轻动作音 | 翻页、打开、拿起、放下等动作是画面重点 | 所有动作都配、与原动作声重复 |
| `ambience_bridge` | 环境衔接音 | 场景原环境声中断或过弱 | 编造广播、警报或画面中不存在的真实事件 |

声音冲突时固定服从：人物有信息的说话 > 关键互动原声 > 必要环境声 > 添加音效 > BGM。对白期间如确需动作音，只在动作瞬间轻放；听不清人物时先降低或删除音效，不能依赖字幕补救。

## 组合与记录

剪辑脚本只增加以下内部字段，不做数值评分：

```text
picture_effect: none | push_in | blur_reveal | flash | motion_blur | frame_freeze | tv_shutdown
person_effect: none | subject_zoom | subject_freeze | outline | reaction_symbol | subject_track
sfx: none | transition | cue | result | comedy | action | ambience_bridge
effect_reason: 一句话说明它强化了什么；全部为 none 时留空
```

同一瞬间 `picture_effect` 与 `person_effect` 不得同时非 `none`。最多允许“一个视觉强化＋一个轻音效”；如果人物原声、画面反应或任一视觉效果已经足够，`sfx` 必须为 `none`。结尾 `tv_shutdown` 和随后出现的 `end_card` 是固定全局模板，不受正文默认 `none` 与情绪省略规则影响。

## 本能验收

完整播放后只判断：

1. 特效是否让事件更清楚，而不是提醒观众“这里加了特效”？
2. 有没有情绪不匹配、重复、廉价或本能想删除的效果？
3. 人物对白、关键互动和固定字幕是否仍然清楚？
4. 关闭全部新增特效后，如果故事和笑点反而更自然，就保留无特效版本。

发现问题直接删除或减弱，不建立面向用户的特效评分表。
